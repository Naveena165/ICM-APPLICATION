# Incentive Management System

A web application for managing incentive plans, participants, and payees.

## Getting Started

1. Install dependencies:
```
npm install
```

2. Start the development server:
```
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Participant search with multiple filters
- Advanced search capabilities
- Results table with sortable columns
- Responsive design

## Project Structure

- `src/App.jsx` - Main application component
- `src/components/SearchForm.jsx` - Search form with filters
- `src/components/SearchResults.jsx` - Results display wrapper
- `src/components/ParticipantTable.jsx` - Data table component
- `src/App.css` - Application styles
